# 研矩 · ResearchGrid

基于 [LitMatrix 1.1.0](https://github.com/bapungiri/litmatrix/tree/v1.1.0) 的独立 Zotero 插件，使用 AGPL-3.0-or-later。可以与 LitMatrix 共存。

## 安装

从 [Gitee 发行版（国内下载）](https://gitee.com/nianyu17/research-grid/releases) 或 [GitHub Releases](https://github.com/liyanyi21/research-grid/releases/latest) 下载 `.xpi` 文件，在 Zotero 的“工具 → 插件”中点击齿轮，选择“Install Plugin From File…”。Gitee 同时提供对应源码 ZIP 和 SHA256SUMS。安装后无需卸载原版 LitMatrix。首次使用建议先选中一个分类。

已在 macOS / Zotero 11.0-beta.3 实测，其他声明版本仍需要兼容性验证。详细记录见 [VALIDATION.md](VALIDATION.md)。

## 使用

1. 在 Zotero 左侧选中一个分类。
2. 选择“工具 → 研矩”，或在分类右键菜单中选择“打开研矩”。
3. 矩阵默认列出当前分类及所有子分类里的文献，包括没有高亮或批注的文献。相同文献去重。
4. 双击单元格进入编辑，或用键盘聚焦后按 Enter；Enter 保存、Shift+Enter 换行、Tab 保存后移至下一格；也可点击小型“保存”按钮。保存失败保留当前草稿。长内容点击“展开编辑”进入弹窗，或“回到表格”继续原草稿；弹窗支持 Command/Ctrl+Enter 保存。
5. 点击顶部研究项目按钮，搜索名称或完整路径，在分类树中展开、折叠并勾选一个或多个分类，点击“应用选择”。也可在 Zotero 主窗口选择多个分类，再点击“使用 Zotero 所选分类”。
6. 点击“项目字段与模板”编辑当前项目的字段名称、填写要求、显示、顺序；也可增加字段、移出或恢复字段。
7. 点击“导出已填 CSV”，选择路径。导出当前搜索/分析状态过滤后的文献，按当前项目的字段名称与顺序导出，包含隐藏字段，不包含已移出的归档字段。
8. 点击标题或“打开原文”打开 PDF/EPUB/HTML 阅读器；没有原文时定位 Zotero 条目。“批注”按钮列出原文批注，点击可跳到对应位置。

## 紧凑工具栏

- 顶部保留项目选择、表格/导图切换和刷新。其余控件默认收起：点击“筛选”“项目与显示”“批量操作”展开，再点一次收起。面板展开状态在本机记住。
- “筛选”包含搜索、分析状态和排序；收起后仍保留条件，按钮会提示启用的条件数，可展开后点“清除筛选”复原。
- “项目与显示”包含 Zotero 当前分类、子分类与标签开关、字段/显示设置、列宽恢复及导入导出。原来的功能入口都在这个面板里。
- “批量操作”包含全选、从 Zotero 勾选和批量 AI；收起不清空勾选，按钮会显示已选篇数。
- 表头使用较小字号和间距，默认仅显示字段名称。悬停列标题可看完整填写要求；在“项目与显示”勾选“表头显示填写要求”可恢复展开说明。编辑窗口和 AI 仍使用完整要求。
- 折叠面板不会替换表格、关闭文字草稿或清空选择；页面、单格内部的阅读位置继续保留。

## 搜索分类与多项目汇总

- 分类选择器使用可折叠树、搜索和复选框。右侧保留已选清单，切换搜索不会清空勾选；“全选当前搜索结果”只选实际匹配项，祖先仅作为层级上下文显示。
- 勾选父分类不会自动勾选子分类；各项目“包含子分类”仍决定该项目读取的文献范围。
- 多选后在同一窗口按项目分区，每个分区保留自己的字段、资料列、标签显示和分析。相同文献在不同项目中保留不同记录，分析、备注和高亮各自保存；不迁移或合并旧笔记。
- 任一分区的单元格和高亮、单篇 AI 总结按该行所属项目操作。页面明确显示项目名称与“项目记录/独立文献”数量。
- 点击顶部“当前操作项目”按钮，会切换操作目标并滚动到该项目的表格分区；再次点击当前项目也能重新定位，横向列位置保留。导图模式下则切换对应项目导图。未保存编辑仍会阻止切换或定位。
- 顶部“当前操作项目”按钮控制字段与显示设置、批量 AI、CSV/待填模板导出和表格导入的目标；这些操作按项目分别进行，窗口内会标明目标项目。批量 AI 只处理当前操作项目已勾选的记录，其他项目的勾选仍保留。
- 搜索和分析状态筛选覆盖所有已选分区。Tools 菜单重新打开矩阵会恢复上次分类选择与操作项目；分类右键入口和“使用 Zotero 所选分类”按主窗口当前选择打开。
- 所选分类消失或读取失败会显示错误，须重新选择或重试；不会把剩余分类当成原来的完整选择。未保存编辑和 AI/字段/导入草稿会阻止切换。

## 标签与 Zotero 条目信息列

- “项目与显示”中的“显示标签”控制文献卡片里的标签，按项目记住。隐藏只影响表格显示，标签仍可搜索，CSV 仍保留标签。
- 展开“项目与显示”后点击“显示选项”，勾选需要的条目信息，可在“已选列顺序”中上下移动，保存后出现在文献列和分析列之间。首次默认不添加额外资料列。
- 可选 22 项：文献标题、作者、年份、出版日期、期刊/会议/书名、条目类型、DOI、网址、摘要、卷、期、页码、出版社、出版地、语言、ISBN、ISSN、访问日期、添加时间、修改时间、其他信息和引用键。作者列显示完整姓名，引用键沿用插件已有的 Zotero/Better BibTeX/Extra 解析结果。
- 这些列直接读取 Zotero，空值显示“—”；需要修改时可点“Zotero 条目”编辑原条目，再刷新矩阵。资料列为只读，不作为 AI 待填分析字段，也不保存到分析子笔记。
- 搜索包含条目资料。已填 CSV 会附加所选资料列，保留所选顺序，并用 `[zotero:字段名]` 区分；导入时自动跳过这些只读资料列。待填模板仍仅包含原有文献识别信息和项目分析字段。
- 标签显示与资料列选择保存在本机的各项目偏好中，暂不跨设备同步。项目分析内容和原文标签均独立于这些显示选择。

## 调节列宽与思维导图

- 拖动表头右侧的分隔线可调节列宽；选中分隔线后，方向键每次调整 10 像素，Shift+方向键调整 50 像素。双击分隔线或按 Home 恢复该列默认宽度；“恢复当前项目列宽”恢复整个当前项目。
- 列宽按项目和字段身份保存：字段改名、调整顺序或暂时隐藏后再显示，仍使用原列宽。多项目表格各自记忆，调整一个分区不会影响其他分区。
- 点击“思维导图”，按“当前操作项目 → 文献 → 分析字段”查看已有分析；多选分类时，可用顶部项目按钮切换导图。导图跟随当前搜索和分析状态筛选，有效字段的非空内容形成节点，长文在详情区完整显示。
- 拖动节点可移动其整个分支；拖动空白处平移，首次以可读字号显示，使用缩放、“100%”、适应画布和折叠/展开按钮整理视图。节点也可通过键盘移动，布局、折叠和缩放在本机按项目保存，重新打开可继续使用。
- 选择文献或字段可查看详情、打开原文或定位 Zotero 条目；双击字段或点击详情中的编辑入口打开同一份分析。保存后表格和导图同步更新；“回到表格”继续同一份编辑草稿。空字段可从文献详情中选择填写。
- 导图展示已有项目分析，不额外调用 AI。布局、列宽保存在本机偏好中；文字修改仍保存到原来的项目分析子笔记。图中连接表示项目、文献与字段的结构关系。

交互参考 [Better Notes 的思维导图与大纲](https://github.com/windingwind/zotero-better-notes/blob/4215a882e9f3528ddd4820c20b2c29e732c14e7e/src/elements/workspace/outlinePane.ts)，本插件使用独立的原生 DOM/SVG 实现。

## Zotero 设置入口

打开 Zotero 的“设置”（Windows / Linux 部分版本称“首选项”），在左侧选择“研矩”。页面提供打开矩阵、编辑项目字段与模板的入口及版本信息。先在 Zotero 主窗口选择一个项目分类，然后进入相应设置。

## 中文字段

任务与证据类型、研究方法与样本、观测指标、核心结论、局限性、与我的研究的关系、我的备注。

默认显示任务与证据类型、观测指标、核心结论和我的备注，其余可在“项目字段与模板”开启。所有字段支持换行和局部文字高亮，可通过每篇文献的“AI 总结”按钮，按当前项目字段生成可核对的草稿。CSV/TSV 中仍使用纯文本。

## AI 按字段总结

1. 打开 Zotero“设置 → 研矩 → AI 字段总结”，填写 OpenAI 兼容 API 地址、模型 ID 与 API Key；地址可以是基础地址（建议包含 `/v1`）或完整 `/chat/completions` URL。
2. 设置默认总结篇幅（简约 / 详细 / 全面）、原文字符上限、超时和可选最大输出 token。“测试连接”只发简短测试句，不发送论文；测试成功后点击“保存 API 设置”。
3. 在论文行点击“AI 总结”。检查目标地址、模型、文本来源与选中字段；默认只勾选空字段。已有分析、个人备注和批注不发送给 API。
4. 可选择本地原文提取文本与摘要，或仅摘要。索引可能不完整；截取、缺少原文及 OCR 等情况会明确显示。只提供局部文本时，AI 无法可靠判断全文内容。
5. 在窗口中用“简约 / 详细 / 全面”按钮调整本次每字段的总结量：简约提取 1–2 句关键事实，详细整理 3–5 项事实，全面按主题列全相关条件、方法和结果。参考字数分别为 40–100、150–300、300–600 字；事实少时短写，不凑篇幅。切换档位不会自动调用 API，也不会删除已有草稿；重新生成前仍会确认替换草稿。
6. 点击“发送到 API 并生成草稿”。生成不会自动写笔记；可取消请求，在预览中编辑、选择结果，再点击“写入选中字段”。写入时统一检查原值，任一选中字段冲突则本次全部拒绝写入。
7. 更改 API 设置后，在预览中点击“刷新 API 设置”。密钥按最终请求地址分别保存在本机 Zotero 密码管理器，不读取其他插件密钥，不存进公共偏好、导出或源码包。无鉴权的回环本地服务可以留空。

仅使用 OpenAI 兼容 Chat Completions 非流式接口，暂不支持 Claude 原生协议、图片识别或后台自动生成。扫描版 PDF 需先 OCR。每次调用可能产生服务商费用，AI 草稿需核对原文，不能替代全文阅读；总结仅提取所提供原文明确报告的客观事实，保留实验条件、样本、比较方向与数值、作者明确陈述的结论和局限；不添加“我的初步解读”、跨情境推断、读者评价或泛泛的证据不足评语。来源中缺失的事实只标记“未提及”；个人备注/项目关系类字段也不代写个人观点。来源覆盖和截断提示保留在窗口中，不重复写入各分析格。篇幅是提示词约束，不保证模型严格满足字数或完全消除错误。不预置任何服务或密钥。

## 多篇文献一起 AI 总结

1. 展开“批量操作”，在矩阵每篇文献旁勾选，或用“全选当前筛选”。也可以在 Zotero 主窗口多选后，点击“勾选 Zotero 中所选”；只选入当前项目的文献。筛选不会清除已选文献，顶部会显示筛选外的数量，切换项目会清空选择。
2. 点击“批量 AI 总结”。一次最多 100 篇，每页展示 10 篇。打开窗口只读取本机文本；核对目标地址、模型、每篇来源、字段及篇幅后，再点击“生成未完成论文的草稿”。每篇单独顺序调用一次 API。
3. 默认逐篇只填写空字段。需要替换已有分析时主动开启覆盖；已有分析和高亮不发送给 API。取消会停止后续处理，保留已完成草稿；再次生成只处理未完成论文，也可单独重试失败论文。
4. 草稿可逐篇编辑、按字段勾选；最后点击“写入选中草稿”。全部选中变更在同一事务保存，任一文字或高亮冲突、保存失败则整批不写入，并保留草稿。窗口关闭前会提示尚未写入的草稿；草稿不在后台持久保存。

批量请求仍使用当前的“简约 / 详细 / 全面”设置和客观事实提示词。调用次数随文献数量增加，实际费用和请求限制由所填服务商决定。

## 阅读时高亮与编辑

- 在表格已有分析文字中直接拖选一句或一段，底部出现高亮工具栏；选择黄色、绿色、蓝色或粉色后立即保存。选择已有高亮后可清除所选部分。
- 高亮或清除高亮只更新当前格；后台读取笔记时保持表格，保存后保留页面横纵位置和单元格内部的滚动位置。
- 单击和拖选保持阅读状态。双击单元格才进入文字编辑，或聚焦后按 Enter。长文本仍可展开弹窗，再返回同一份文字草稿。
- 高亮直接作用于表格中选中的文字，点颜色即自动保存，无高亮预览或额外保存步骤。输入框只编辑文字，保存后回到表格即可继续划选高亮。
- 高亮随当前项目的 Zotero 分析子笔记保存，刷新、重开仍可读取，并可随笔记同步。编辑文字时尽量保留未修改部分的高亮；被替换的片段需要重新标记。
- 仅支持当前单元格内的分析文字，不修改原文 PDF 批注。CSV/TSV 导出只保留文字，重新导入不会恢复颜色；直接覆盖文本时会保留未受修改影响的现有高亮。

## 导出待填模板与导入表格

1. 配置好当前项目的字段和填写要求，点击“导出待填模板”，选择 CSV 或 TSV。导出当前筛选的文献，包含隐藏的有效字段；分析格子全部留空，不导出已有分析或备注。
2. 模板的首条“填写要求”行列出各字段要求，后续每篇文献一行。可复制窗口中的提示词，把模板和相应论文 PDF/原文一起交给其他 AI；模板只含元数据，不包含论文全文。请保留项目标识、文献标识、文献 Key、表头末尾的字段 ID。
3. 拿到填好的表格后点击“导入表格”，选择文件或粘贴 CSV/TSV，点击“解析并预览”。界面显示列对应关系、文献匹配方式及每个字段的原内容和导入内容；未识别的列可以手动映射。
4. 默认只填空字段，空单元格跳过，已有内容保留。需要覆盖时主动勾选“允许覆盖已有分析”；只有同时勾选“把空单元格清空已有值”才会清空原值。确认预览、勾选文献后点击“确认导入选中内容”。全选作用于全部分页。
5. 只写入当前项目已有文献的分析字段，不创建文献或修改标题、作者等元数据。优先按稳定 Zotero 标识匹配；没有标识时支持唯一引用键或完全一致的唯一标题。错误标识、跨项目、重复行或歧义会阻止对应行导入。所选行在同一事务保存，任一原值冲突或保存失败则整批不写入，输入和预览保留。

兼容本插件的旧 CSV 导出，也可手动对应其他 AI 的字段列。支持 UTF-8 CSV/TSV、带 BOM 的 UTF-16 TSV，以及 AI 返回的 CSV/TSV 代码块。暂不读取 XLSX、Markdown 表格或自动新建字段；遇到编码提示请在 Excel/WPS 中另存为 UTF-8 CSV 或 Unicode TSV。一次导入最多 10 MB、10000 条记录、100 列，单格最多 200000 字符；待填模板最多 9999 篇文献，另加一行填写要求。导入不调用 API，公式与 HTML 均作为纯文本保存。

## 项目字段与通用模板

- 每个项目拥有独立的字段名称、填写要求、顺序与显示状态；填写要求会显示在列标题与编辑区域。
- 字段改名保持原身份，已写内容仍可读取；“移出项目”只归档字段，历史分析保留，可随时恢复。
- 内置“通用文献分析”“实证研究”“理论与综述”三种模板。选择后点击“应用到项目草稿”，检查后点击“保存项目字段”才对当前项目生效。
- 可把当前字段与填写要求“另存为通用模板”，在其他项目复用。模板不包含任何文献分析或备注，应用后是独立副本。
- 项目字段定义、显示偏好和自建模板保存在本机 Zotero Prefs，暂不跨设备同步；文献分析与备注仍保存在 Zotero 子笔记中并使用 Zotero 同步。

## 项目隔离与数据保存

- 一个分类就是一个项目，主分类与子分类分别打开时是不同项目。
- 父分类包含子分类时，编辑的仍是父分类项目的分析。
- 项目身份由个人库/群组身份与分类 key 构成；分类改名或移动不会改变身份。
- 同一文献可在多个项目拥有独立子笔记。文献即使移出分类，已经写下的项目子笔记仍保留。
- 仅主动保存分析时创建或修改本插件的子笔记；不会改原有 LitMatrix 笔记、元数据或批注。
- 子笔记标题为“研矩 · 项目名”，以专用标签识别项目，以字段属性标识固定字段 ID。不要移除项目笔记上的 `_projectlitmatrix:v1:` 标签。
- 同项目存在重复笔记时阻止编辑，避免静默选错笔记；请在 Zotero 中合并。
- 编辑保存前重新检查当前字段，检测其他窗口修改；发生冲突时保留输入并提示核对。
- 笔记与其标签使用 Zotero 原生同步。显示偏好使用本地 Zotero Prefs，不承诺跨设备同步。
- 只读群组文献库可查看和导出；独立 PDF 附件可展示和跳转，创建父文献条目后可填写分析。

## CSV 格式

UTF-8 BOM，CRLF 换行，所有单元格双引号转义，支持逗号、引号、多行文本及中文。对可能被电子表格当作公式的内容加单引号。包含文献、项目笔记与原文的 Zotero 链接。链接在安装 Zotero 且有对应文献的电脑上可用。

## 开发与打包

当前插件仅使用原生 JS/HTML/CSS，运行时没有 npm 依赖。

```sh
npm ci
npm test
npm run build
```

构建依赖 Python 3 标准库；产物为 `dist/research-grid-0.9.3.xpi`，另附对应源码包与 SHA256SUMS。在 Zotero 插件管理器选择“Install Plugin From File…”安装。插件不提供自动更新，后续使用新 XPI 手动更新。Zotero 强制要求提供 HTTPS 更新地址，因此清单使用本机端口 0 的不可连接地址作为占位；不会向远程服务检查更新。`content/updates.json` 为未来发布时可用的空清单模板。

## 文件组织

- `plugin/bootstrap.js`：独立生命周期、菜单、窗口；不修改 LitMatrix 的全局对象或标签页钩子。
- `plugin/content/core.js`：字段、项目身份、笔记编解码、论文级搜索和 CSV。
- `plugin/content/repository.js`：Zotero 数据读写、项目笔记隔离、权限和冲突检查、原文跳转。
- `plugin/content/preferences.xhtml` / `preferences.js`：Zotero 原生设置页容器与控制器。
- `plugin/content/fields.js` / `fields.css`：项目字段草稿、归档恢复与通用模板管理。
- `plugin/content/project-picker.js` / `project-picker.css`：可搜索、折叠、多选的分类树与已选清单。
- `plugin/content/column-widths.js` / `column-widths.css`：表头拖动与键盘列宽调整、稳定列身份。
- `plugin/content/mindmap.js` / `mindmap.css`：项目思维导图、节点拖动、画布和布局。
- `plugin/content/display.js` / `display.css`：项目标签显示和只读 Zotero 资料列选择、排序。
- `plugin/content/ai.js`：OpenAI 兼容配置、请求、字段提示与严格结果解析。
- `plugin/content/ai-dialog.js` / `ai-dialog.css`：来源/发送范围、AI 草稿预览与确认写入。
- `plugin/content/ai-batch.js` / `ai-batch.css`：多篇顺序生成、逐篇草稿和统一确认写入。
- `plugin/content/highlights.js` / `highlights.css`：表格划选、高亮工具栏与安全显示。
- `plugin/content/credentials.js`：按 API 地址隔离的本机密钥存储。
- `plugin/content/table-io.js`：待填模板、CSV/TSV 解析、列映射与文献匹配计划。
- `plugin/content/table-dialog.js` / `table-dialog.css`：文件或粘贴导入、旧值/新值预览与选中写入。
- `plugin/content/matrix.js`：中文矩阵、编辑、字段偏好、刷新和导入导出交互。
- `tests/`：核心数据行为与 Zotero 适配器测试。
- `scripts/build.py`：XPI 与对应源代码打包。
